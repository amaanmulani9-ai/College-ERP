# Enterprise Settings Keyboard Shortcuts Reference

> **Component**: `frontend/src/settings/final/SettingsShortcutsDialog.tsx`  
> **Trigger**: Press `?` anywhere in Settings  
> **Version**: v0.34.0-ui-settings-final  

---

## Global & Navigation Shortcuts

| Shortcut | Category | Description |
|---|---|---|
| <kbd>?</kbd> or <kbd>Shift</kbd> + <kbd>?</kbd> | Global | Open Keyboard Shortcuts Reference |
| <kbd>Ctrl</kbd> + <kbd>/</kbd> | Global | Open Global Settings Search Modal |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Global | Open ERP Command Palette |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Layout | Toggle Settings Sidebar |
| <kbd>Ctrl</kbd> + <kbd>H</kbd> | Navigation | Jump to Settings Home |
| <kbd>Alt</kbd> + <kbd>←</kbd> | Navigation | Navigate Back |
| <kbd>Esc</kbd> | Dialogs | Close active modal, dialog, or search |

---

## Settings Administration & Form Shortcuts

| Shortcut | Category | Description |
|---|---|---|
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Action | Save Current Settings Configuration |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Action | Undo Last Configuration Modification |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | Features | Open Feature Flags Management Panel |

## System & Diagnostics Shortcuts

| Shortcut | Category | Description |
|---|---|---|
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> | System | Open System Health Monitor |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> | System | Open Audit Log Center |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>D</kbd> | UI | Toggle Dark / Light Theme Mode |
| <kbd>F11</kbd> | View | Toggle Full Screen Mode |

---

## Usage Instructions

1. Press <kbd>?</kbd> when anywhere in the Settings Center to bring up the interactive shortcuts reference.
2. Filter shortcuts by category (Navigation, Settings, System, UI) using the top category bar.
3. Shortcuts work across desktop browsers (Chrome, Firefox, Edge, Safari).
