# Enterprise Mobile Touch Gestures & Hardware Shortcuts

> **Document**: Mobile Shortcuts & Gestures Guide  
> **Module**: `frontend/src/mobile/final/MobileShortcutsDialog.tsx`  

---

## Touch Gestures Reference

| Gesture | Action |
|---|---|
| **Swipe Left / Right** | Switch between open workspace sub-tabs |
| **Pull Down** | Refresh live activity log feed & notifications |
| **Tap & Hold** | Pin or unpin module from Favorites grid |
| **Double Tap Title** | Maximize visual chart viewer to fullscreen |
| **Edge Swipe Right** | Toggle mobile navigation drawer |

---

## Hardware Keyboard Shortcuts

| Key Combo | Action |
|---|---|
| <kbd>⌘</kbd> + <kbd>K</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | Open Workspace Touch Search Modal |
| <kbd>⌘</kbd> + <kbd>B</kbd> / <kbd>Ctrl</kbd> + <kbd>B</kbd> | Toggle Navigation Drawer |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> | Open AI Workspace Assistant Panel |
| <kbd>Esc</kbd> | Close active modal dialog or drawer overlay |
