# Repository Directory Structure

```
College-ERP-main/
├── backend/                  # Django 5.1 REST Framework Backend
│   ├── apps/                 # 30 Domain Applications
│   ├── config/               # Settings, URLs, WSGI, ASGI
│   └── manage.py             # Django Manager Script
├── frontend/                 # React 19 + TypeScript + Vite Frontend
│   └── src/
│       ├── components/       # Design System, Auth, Dashboards, Workspace
│       ├── mobile/           # Touch-first Mobile & PWA Suite
│       ├── reporting/        # Report Builder & Visual Charts
│       ├── settings/         # System Administration & Security
│       └── ux/               # Motion, State, Accessibility, Performance Systems
├── docs/                     # Production Architecture & Deployment Documentation
├── .github/                  # CI/CD Workflows, Issue & PR Templates
├── docker-compose.yml        # Docker Multi-Container Specification
├── package.json              # Vite & React Dependencies
├── pyproject.toml            # Python Tooling Configurations
├── requirements.txt          # Production Python Requirements
└── README.md                 # Primary Production README
```
