# Enterprise Workspace Keyboard Shortcuts

## Opening the Shortcuts Dialog

Press `?` (when not in an input/textarea) or `Ctrl+Shift+?` to open the searchable Shortcuts Dialog.

---

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Open Command Palette |
| `Ctrl + F` | Global Search |
| `Ctrl + Home` | Go to Dashboard |
| `Alt + ←` | Go back |
| `Alt + →` | Go forward |

## Workspace

| Shortcut | Action |
|----------|--------|
| `Ctrl + Tab` | Window Switcher (Docking System) |
| `Ctrl + W` | Close Active Window |
| `Ctrl + T` | New Workspace Tab |
| `Ctrl + \` | Toggle Left Sidebar |
| `Ctrl + Shift + P` | Toggle Productivity Hub |
| `Ctrl + ,` | Open Workspace Preferences |
| `?` | Open Shortcuts Dialog |
| `Ctrl + Shift + ?` | Open Shortcuts Dialog |

## AI Assistant

| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + A` | Toggle AI Dock |
| `Enter` | Send AI message |
| `Shift + Enter` | Insert newline in chat |
| `Ctrl + Shift + N` | New AI conversation |

## Editor / Forms

| Shortcut | Action |
|----------|--------|
| `Ctrl + S` | Save / Submit Form |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + C` | Copy |
| `Ctrl + V` | Paste |

## Dialogs

| Shortcut | Action |
|----------|--------|
| `Esc` | Close dialog / panel |
| `Enter` | Confirm dialog |
| `F1` | Open Help Center |
| `?` | Open Shortcuts Dialog |
